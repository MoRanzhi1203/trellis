# 12 天词汇 · 词根与记忆分析

> 依据：12 张单词表截图（每天一张），绿色加粗为新东方标记的主词，其余为与主词同根、派生或同义相关的词。
> 说明：词源采用常见拉丁/希腊/古英语来源，仅作记忆线索；不确定的形近词会单独标注，不冒充同源。

---

## 0. 总览：12 天不是 12 堆词，而是 4 类结构

| 类型 | 特征 | 典型天 |
|---|---|---|
| **同根派生** | 一个词根 + 前缀/后缀，意义可推 | Day 1（work/stat）、Day 10（form/firm）、Day 12（fin/volv） |
| **同义聚合** | 主词 + 近义词/反义词，靠语义场记 | Day 4（control/curb）、Day 6（increase/decrease） |
| **构词联想** | 主词能拆出前缀，带出一串 | Day 5（para-）、Day 9（in-/ob-） |
| **主题词群** | 同一话题的不同词性/搭配 | Day 2（社会/公共）、Day 3（人/政府） |

**主词（绿色）共约 30 个**，其余 180 余词基本都能挂到主词上：

```
work ── state ── change ── social ── public ── human ── take ── government
control ── accord ── mean ── direction ── paragraph ── section ── sheet
question ── increase ── research ── mark ── science ── company ── system
different ── example ── found ── pay ── place ── believe ── influence
data ── observe ── firm ── interest ── product ── effect ── define
energy ── fail ── involve
```

## Day 1 · work / state

**主词**：work（绿）、state（绿）

### work 族

| 词 | 拆解 | 记忆 |
|---|---|---|
| work | 古英语 weorc「做、劳作」 | 核心义：工作；引申：运转、起作用 |
| work against | work + against（对抗） | 工作与…相反 → 妨碍 |
| work on | work + on（朝向） | 朝着…做 → 从事 |
| work out | work + out（出来） | 做出来 → 解决、算出、发展顺利 |
| workout | work + out | 把身体「练出来」→ 锻炼 |
| workplace | work + place | 工作的地方 |
| workaholic | work + -aholic（成瘾） | 对工作上瘾的人 |
| workstation | work + station | 工作台 |
| patchwork | patch（补丁）+ work | 拼补出来的东西 → 拼凑物 |

**记忆钩**：work 的短语用「方向词」记——against 对着干、on 朝着做、out 做出来。

### state 族（拉丁 stare「站立」）

| 词 | 拆解 | 记忆 |
|---|---|---|
| state | stare → status「站立的状态」 | 站出来的样子 → 状态；政治实体 → 州/国家；站定说法 → 声明 |
| stated | state + -ed | 被声明过的 → 规定的 |
| statement | state + -ment | 声明（名词） |
| overstate | over-（过度）+ state | 说过头 → 夸大 |
| status | 拉丁 status | 站立的位置 → 地位、身份 |
| statute | 拉丁 statuere「设立」 | 立下来的 → 法令 |
| estate | 拉丁 status（身份/状况） | 身份对应的财产 → 地产、遗产 |
| statistical | statistics（统计）+ -al | 统计的（注意：不是「国家的」） |

**易混**：`state` 三词性（n. 州/状态；v. 声明；adj. 州的）；`status` 是「地位」，不是「州」；`estate` 与 `state` 同源但意义已分化到「财产」。

**记忆钩**：stat = 站。站着不动 → 状态；站成一片 → 国家；站着说 → 声明；站定规则 → 法令。

## Day 2 · change / social / public

**主词**：change（绿）、social（绿）、public（绿）
**承接**：statistical / statistic / stationary 是 Day 1 stat 的延伸。

### stat 延伸

| 词 | 拆解 | 记忆 |
|---|---|---|
| statistical | statistics + -al | 统计的 |
| statistic | state（国家状况）→ statistics | 统计数字；statistics 统计学 |
| stationary | 拉丁 statio「站立」+ -ary | 站着不动 → 静止的（≠ stationery 文具） |

### change（拉丁 cambire「交换」）

| 词 | 拆解 | 记忆 |
|---|---|---|
| change | cambire | 交换 → 改变；零钱（交换来的） |
| exchange | ex-（出）+ change | 换出去 → 交换、交易所 |

### social（拉丁 socius「同伴」）

| 词 | 拆解 | 记忆 |
|---|---|---|
| social | socius + -al | 同伴的 → 社会的、社交的 |
| asocial | a-（无）+ social | 不社交的 |
| sociable | soci- + -able | 能交往的 → 合群的 |
| society | soci- + -ety | 同伴的集合 → 社会 |
| sociologist | soci- + -logist | 研究社会的人 |

### public（拉丁 populus「人民」→ publicus「公共的」）

| 词 | 拆解 | 记忆 |
|---|---|---|
| public | publicus | 人民的 → 公共的；公众 |
| publicly | public + -ly | 公开地 |
| publicize | public + -ize | 使公开 → 宣传 |
| publication | public + -ation | 使公开的产物 → 出版物 |
| republican | re-（事务）+ public + -an | 公共事务的拥护者 → 共和的 |

**记忆钩**：soci = 同伴，publ = 人民，change = 交换；三者都是「人和人的关系」主题，串起来记。

## Day 4 · accord / mean / direction

**主词**：accord（绿）、mean（绿）、direction（绿）
**同义群**：control / curb / chancellor / record / steer 围绕「控制、记录、引导」。

### accord（ad- 向 + cor 心）

| 词 | 拆解 | 记忆 |
|---|---|---|
| accord | ad- + cor（心） | 心往一处 → 一致、协议 |
| with one accord | 一心 | 一致地 |
| in accord(ance) with | 与…同心 | 按照、与…一致 |
| of one's own accord | 出于自己的心 | 自愿地 |

### mean（古英语 mænan「意图」）

| 词 | 拆解 | 记忆 |
|---|---|---|
| mean | mænan | 意思是；打算；平均的（居中）；卑鄙的（古义「低劣」） |
| meaning | mean + -ing | 意义 |
| meaningful | meaning + -ful | 有意义的 |
| means | mean + -s | 手段（达到目的的东西） |
| meantime | mean（中间）+ time | 其间 |
| meanwhile | mean + while | 同时 |

### direction（拉丁 dirigere「引导」）

| 词 | 拆解 | 记忆 |
|---|---|---|
| direct | di-（分）+ regere（引导） | 直接引导 → 直接的；指导 |
| direction | direct + -ion | 方向；说明 |
| director | direct + -or | 引导者 → 主任、导演 |
| steer | 同义（驾驶） | 与 direct 同义场 |

### 控制与记录

| 词 | 记忆 |
|---|---|
| control | contra-（反）+ rol（卷轴）→ 对照账本 → 控制 |
| curb | 马嚼子 → 勒住 → 控制 |
| chancellor | 拉丁 cancellarius（门栏/秘书）→ 大臣 |
| record | re-（回）+ cor（心）→ 记回心里 → 记录 |

**记忆钩**：accord 用「心」记（同心、违心、自愿）；mean 用「中间」记（mean = 平均/居中）；direct 用「引」记。

## Day 5 · paragraph / section / sheet / question

**主词**：paragraph（绿）、section（绿）、sheet（绿）、question（绿）
**前缀群**：para-（旁/防/反）是这一天的核心。

### graph（希腊 graphein「写」）

| 词 | 拆解 | 记忆 |
|---|---|---|
| graph | graphein | 写出来的 → 图表 |
| paragraph | para-（旁）+ graph | 写在旁边的分隔 → 段落 |
| graphic | graph + -ic | 书写/绘画的 → 形象的 |
| hijack | 劫持（与 graph 无关，同屏词） | 单独记 |

### para- 家族（旁、防、反）

| 词 | 拆解 | 记忆 |
|---|---|---|
| parallel | para-（旁）+ allel（彼此） | 彼此在旁 → 平行 |
| paradox | para-（反）+ dox（观点） | 反着说 → 悖论 |
| parachute | para-（防）+ chute（落） | 防坠落 → 降落伞 |
| paralysis | para-（旁）+ lysis（松开） | 旁边松掉 → 瘫痪 |

### section（拉丁 secare「切」）

| 词 | 拆解 | 记忆 |
|---|---|---|
| section | secare + -ion | 切出来的一块 → 部分、部门 |
| sector | sect + -or | 切出的扇区 → 部门、行业 |
| insect | in-（入）+ sect（切） | 身体分节的 → 昆虫 |
| segment | seg-（切）+ -ment | 切下的段 |

### sheet / question

| 词 | 记忆 |
|---|---|
| sheet | 古英语 scēat「布片」→ 床单、一张 |
| sheer | 古英语 scīr「纯净」→ 纯粹的、陡峭的（**与 sheet 形近但不同源**） |
| question | 拉丁 quaerere「寻求」→ 提问；query 同根；questionable 可疑的 |

**记忆钩**：para- 三义——旁（parallel/paragraph）、防（parachute）、反（paradox）；sect = 切（section/sector/insect/segment）。

## Day 6 · increase / research / mark

**主词**：increase（绿）、research（绿）、mark（绿）

| reduction | reduce + -tion | 减少（名词） |
| mute | 拉丁 mutus「沉默」 | 无声的；减弱声音 |

|---|---|---|

| researcher | research + -er | 研究者 |
| rake | 耙子 → 耙找 → 搜寻 | 与 search 同义场 |

### mark（古英语 mearc「边界记号」）

| 词 | 拆解 | 记忆 |
|---|---|---|
| mark | mearc | 记号、痕迹、分数 |

### 其他

| 词 | 记忆 |
|---|---|
| matter | 拉丁 materia「物质」→ 事情、要紧 |

| query | quaerere「寻求」→ 疑问 |

**记忆钩**：cresc = 长（increase/decrease）；search = 绕圈找（research = 反复找）；mark = 做记号（remark = 再标记 → 评论）。

## Day 10 · form / firm

|---|---|---|

| confined | confine + -ed | 被限制的 |
| refine | re-（反复）+ fin（极限） | 反复到极致 → 提炼 |
| finish | fin + -ish | 到终点 → 完成 |

三条支流：划界（define/confine）、到终点（finish）、到极致（refine）。

### ergon（希腊「工作」）

| 词 | 拆解 | 记忆 |
|---|---|---|
| energy | en-（在内）+ ergon | 内在的功 → 能量、精力 |
| energetic | energy + -etic | 充满能量的 |

### fallere / might

| 词 | 记忆 |
|---|---|
| fail | 拉丁 fallere「欺骗/失误」→ 失败、未能 |
| failure | fail + -ure（名词，不是 -er） |
| might | 古英语 miht「能力」→ 力量；情态动词「可能」 |

### volv（拉丁 volvere「卷、转」）

| 词 | 拆解 | 记忆 |
|---|---|---|
| involve | in-（往里）+ volv | 卷进去 → 牵涉 |
| involved | involve + -ed | 有关的；棘手的 |
| involvement | involve + -ment | 参与 |
| revolve | re-（转回）+ volv | 绕圈转 |
| revolution | revolve + -ion | 旋转 → 革命 |
| revolutionary | revolution + -ary | 革命性的 |
| evolve | e-（往外）+ volv | 展开卷轴 → 演变 |
| evolution | evolve + -ion | 演变、进化 |

**记忆钩**：fin 三支（界/终/极）；volv 三向（in 卷入、re 回转、e 展开）；energy 的 ergon 与 work 同义（都是「做功」），可与 Day 1 的 work 串联。

## 记忆节奏建议

1. **先记主词，不记派生**：每天只背绿色词 + 词根义（如 stat=站、form=形、duc=引、fin=界）。
2. **用「前缀方向」推派生**：in- 向内、e-/ex- 向外、re- 回/再、de- 向下、con- 共同、dis- 分开、pre- 前、pro- 前、sub- 下。看到生词先拆前缀。
3. **每天 5 分钟「反向推」**：遮住中文，看词猜义；猜错的地方回到词根。
4. **按跨天线索复习**：复习 stat 时连 Day 2 的 stationary/statistic 一起看；复习 place 时连 Day 9 的 replace/displace。
5. **易混单独列**：stationary/stationery、sheer/sheet、form/formidable、state/status/estate、confine/confined、revolution 的「旋转」原义。
