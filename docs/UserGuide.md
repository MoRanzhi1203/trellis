# Trellis 用户操作说明

## 1. 启动

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1   # 首次
powershell -ExecutionPolicy Bypass -File scripts/start.ps1   # 日常
```

- 前端：<http://127.0.0.1:8123>
- 接口文档：<http://127.0.0.1:8123/docs>

启动脚本不会删除或重建已有数据库。

## 2. 首页

显示词库总量、今日待复习、今日正确率、连续学习天数、薄弱词和最近复习记录。所有数字由数据库实时计算。

## 3. 词库

- 搜索框支持英文与中文释义。
- 「新增词条」填写 headword、词性、中文释义即可；保存后写入 SQLite。
- 点击表格行查看详情：音标、拼写变体、义项、搭配、例句、构词说明（待审核标签）。
- 「归档」把词条标记为 `archived`，不会删除学习历史。

## 4. 学习与复习

- 打开页面即加载到期卡片（默认 FSRS）。
- 先看题面，点「显示答案」，再选「忘记 / 困难 / 记得 / 简单」。
- 每次提交由后端计算下一次复习时间；刷新或重启不会丢记录。
- 重复提交同一请求（相同 `client_token`）不会重复计分。

## 5. 知识图谱

- 两种模式：
  - **探索**：跨词族网络，默认加载最多 220 个节点。
  - **学习单元**：选择词书单元，只看该单元的词族结构。
- 拖拽、缩放、点击节点查看关系；可切换深色主题。
- 虚线橙色边表示「待审核」的派生关系。

## 6. 导入与备份

- **运行迁移**：幂等导入旧版 `words.js`、`词族网络图.html`、Excel、Markdown。重复执行只合并、不重复创建。
- **创建备份**：在 `data/local/backups/` 生成带时间戳的 `.db`。
- **恢复**：输入备份文件名（只允许备份目录内的文件），恢复前会自动保存当前库为 `before-restore.db`。

## 7. 常见问题

| 问题 | 处理 |
|---|---|
| 页面打不开 | 确认 `scripts/start.ps1` 两个进程都在运行；检查 8000/5173 端口 |
| 没有到期卡片 | 先到「导入与备份」运行迁移，或在词库中新增词条 |
| 想回退数据库 | `data/local/backups/` 选择备份恢复 |
| 修改词条后图谱没变 | 图谱页刷新；节点与词条通过 `lexeme_id` 关联，词条名称变化会同步显示 |

## 8. 数据与隐私

- 数据库与学习记录只在本地，`.gitignore` 已排除 `*.db`、`backups/`。
- 服务默认只监听 `127.0.0.1`，无鉴权，请勿直接暴露到公网。
